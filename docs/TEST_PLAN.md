# План ручного тестирования Firefox Backup Manager

Этот план предназначен для проверки ветки `development` на тестовой Windows-машине. Используйте отдельный тестовый профиль Firefox и отдельную папку назначения. Не проводите первые испытания на единственной копии важного профиля.

## Подготовка

- [ ] Создать или выбрать отдельный тестовый профиль Firefox.
- [ ] Добавить тестовые закладки и несколько тестовых записей, не содержащих настоящих паролей.
- [ ] Подготовить локальную папку назначения.
- [ ] Убедиться, что установлен 7-Zip.
- [ ] Скомпилировать приложение из одной ревизии исходника и сохранить SHA-256.

## Сборка

- [ ] Компилятор найден скриптом.
- [ ] Ошибок C# нет.
- [ ] Создан EXE ненулевого размера.
- [ ] x86 и x64 проверяются отдельно, если обе архитектуры заявляются поддерживаемыми.

## Позитивные сценарии

- [ ] При закрытом Firefox настройка создаёт первую резервную копию.
- [ ] Созданный архив проходит команду `7z t`.
- [ ] При заданном пароле архив требует пароль, а имена файлов не видны до его ввода.
- [ ] Неверный пароль приводит к ошибке проверки.
- [ ] Пустой пароль создаёт незашифрованный архив и это ясно обозначено пользователю.
- [ ] Итоговое имя архива уникально при повторных запусках.
- [ ] После успешной первой копии задача Планировщика существует.
- [ ] Задача запускается при старте и имеет ожидаемую учётную запись.
- [ ] Логи содержат понятный итоговый статус и не содержат пароль.

## Негативные сценарии

- [ ] Запущенный Firefox приводит к отмене резервирования без завершения процесса.
- [ ] Отсутствующий 7-Zip приводит к ошибке; старые архивы не удаляются.
- [ ] Недоступный каталог профиля приводит к ошибке.
- [ ] Недоступный каталог назначения приводит к ошибке.
- [ ] Недостаток места приводит к отмене операции.
- [ ] Повреждённый DPAPI-блок приводит к отмене; открытый архив не создаётся.
- [ ] Повреждённый временный архив не публикуется под окончательным именем.
- [ ] Прерывание 7-Zip не удаляет старые проверенные копии.
- [ ] Два параллельных запуска в одной папке не выполняются одновременно.
- [ ] Повторный запуск не перезаписывает предыдущий архив.
- [ ] Ошибка регистрации задачи не показывается как успешная настройка.

## Восстановление

- [ ] Из тестового архива извлечь профиль в отдельную пустую папку.
- [ ] Убедиться в наличии основных файлов профиля.
- [ ] Подключить тестовую копию через менеджер профилей Firefox.
- [ ] Запустить Firefox с тестовым профилем.
- [ ] Проверить тестовые закладки и другие контрольные данные.

## Ограничения

- Проверка только команды `7z t` — это не end-to-end тест восстановления.
- Поведение задачи от имени SYSTEM нужно проверить отдельно для каждого целевого типа хранилища.
- Перед выпуском стабильной версии необходимо повторить тесты на каждой заявленной поддерживаемой версии Windows.
