# Руководство пользователя Firefox Backup Manager

Руководство для текущей версии в ветке `development`.

> **Важно:** изменения резервного механизма ещё требуют сборки и испытаний на Windows. Не используйте development как единственную копию важных данных. Перед экспериментами сохраните независимую резервную копию профиля другим способом.

---

## 1. Требования

- Windows с .NET Framework 4.x.
- Windows PowerShell с модулем ScheduledTasks для установки задачи автозапуска.
- Установленный 7-Zip (`7z.exe`) в одном из стандартных каталогов Program Files.
- Права администратора для настройки задачи Планировщика Windows.
- Доступ к исходному профилю и каталогу хранения из текущего процесса и, затем, из контекста `SYSTEM`.

Для первого теста рекомендуется локальный диск. Сетевые и съёмные диски пока не считаются проверенными для фонового запуска от имени `SYSTEM`.

## 2. Сборка

1. Поместите `compile.bat` и `compiler_code.cs` в одну папку, доступную для записи.
2. Запустите `compile.bat`.
3. Если компиляция прошла успешно, появится `Firefox_Backup_Manager.exe`.
4. Скрипт выводит SHA-256 исходника и EXE. Это контрольные отпечатки файлов, а не цифровая подпись и не подтверждение происхождения бинарного файла.
5. Запускайте приложение от имени администратора для установки задачи автозапуска.

## 3. Первоначальная настройка

1. Полностью закройте Firefox. Убедитесь, что процессы Firefox исчезли из Диспетчера задач.
2. Запустите `Firefox_Backup_Manager.exe` от имени администратора.
3. Нажмите «Включить / Настроить авто-бэкап».
4. Выберите профиль Firefox.
5. Выберите каталог резервных копий. Не выбирайте папку внутри самого профиля Firefox.
6. При необходимости задайте пароль. Пароль чувствителен к регистру и пробелам; введённое значение не обрезается. Пустое поле создаёт незашифрованный архив.
7. Программа создаст временный архив, проверит его через 7-Zip и только после успешной проверки опубликует итоговый файл.
8. После создания первой копии программа сохранит `config.ini` и зарегистрирует задачу при старте Windows.

Приложение не завершает Firefox принудительно. Если обнаружен хотя бы один процесс Firefox на компьютере, резервирование будет отменено. Это консервативная проверка: она может блокировать резервирование выбранного профиля, даже если запущен другой профиль или другая пользовательская сессия.

Если Firefox запускается во время создания копии, временный архив не публикуется.

## 4. Шифрование и пароль

Если указан пароль, формат 7z использует AES-256, а `-mhe=on` шифрует заголовки архива. Без пароля архив не зашифрован.

Сохранённое значение пароля защищается Windows DPAPI с областью `LocalMachine`. Это не аппаратное шифрование и не гарантия защиты от администратора или вредоносной программы с достаточными правами на том же компьютере.

> Пароль передаётся 7-Zip через перенаправленный стандартный ввод в UTF-8, а не в аргументах командной строки. Пароль всё равно кратковременно находится в памяти приложения и не защищён от администратора или вредоносной программы с достаточными правами на этой машине.

Если сохранённый DPAPI-пароль не удаётся расшифровать, резервирование прекращается; открытый архив вместо зашифрованного не создаётся.

## 5. Автозапуск

После настройки создаётся задача `Firefox_Local_AutoBackup`:

- запускается при старте Windows;
- работает от имени `SYSTEM`;
- разрешает запуск и продолжение работы при питании от батареи;
- запускает EXE с аргументом `--silent-backup`.

Каталог назначения должен быть доступен системной учётной записи при запуске. Сопоставленные сетевые диски текущего пользователя обычно не подходят для задачи SYSTEM без отдельной настройки доступа.

Если при старте Windows Firefox уже работает, каталог назначения недоступен, не хватает места, не найден 7-Zip или архив не прошёл тест, задача завершится с ошибкой. Старые проверенные копии при этом не удаляются.

## 6. Файлы в каталоге резервных копий

В каталоге назначения создаются:

- архивы вида `ИмяПрофиля_ГГГГ-ММ-ДД_ЧЧ-мм-сс_ID.7z`;
- журнал `backup_log.txt`;
- постоянный файл блокировки `.firefox-backup-manager.lock`.

Файл блокировки остаётся в каталоге; эксклюзивная блокировка удерживается только во время операции и освобождается при завершении процесса.

Пароль не записывается в журнал. Вывод 7-Zip сохраняется для диагностики.

## 7. Ротация

Архивы старше 30 дней удаляются только после успешного создания, проверки и публикации новой копии. Если новая копия не создана или тест не пройден, ротация не запускается.

В текущей версии нет настройки срока хранения и нет гарантии минимального количества старых архивов. Используйте независимую копию на другом носителе.

## 8. Отключение автозапуска

1. Запустите приложение от имени администратора.
2. Нажмите «Отключить авто-бэкап и удалить конфиг».
3. Программа удалит задачу Планировщика и `config.ini`, если удаление подтверждено.
4. Архивы резервных копий не удаляются. Файл `.firefox-backup-manager.lock` также может остаться; это нормально.

## 9. Проверка и восстановление

Текущий код проверяет созданный архив командой `7z t`. Это подтверждает читаемость контейнера, но не заменяет полноценную проверку восстановления.

Восстановление из интерфейса пока не реализовано. Для ручного восстановления используйте 7-Zip и сначала извлекайте архив в отдельный каталог. Не распаковывайте поверх действующего профиля. Перед подключением восстановленного профиля закройте Firefox и сохраните ещё одну независимую копию текущих данных.

## 10. Диагностика

| Ситуация | Что проверить |
|---|---|
| Firefox запущен | Закройте все процессы Firefox и повторите операцию |
| 7-Zip не найден | Установите 7-Zip в стандартный каталог Program Files |
| Недостаточно места | Освободите место на целевом диске |
| Каталог недоступен | Проверьте путь и права; для SYSTEM проверьте отдельный доступ |
| Ошибка DPAPI | Конфигурация могла быть перенесена или повреждена; не удаляйте её до выяснения причины |
| Архив не прошёл тест | Не используйте этот архив; предыдущие проверенные копии должны остаться на месте |
| Задача не найдена | Повторите настройку от имени администратора и проверьте ScheduledTasks |

---

## 11. Известные ограничения

- Работа с открытым профилем Firefox не поддерживается.
- Полная поддержка всех вариантов `profiles.ini` не гарантируется.
- NAS и сетевые диски под SYSTEM требуют отдельных испытаний.
- Автоматическое восстановление профиля из интерфейса ещё не реализовано.
- Пароль кратковременно находится в памяти приложения и передаётся через pipe; защита от локального администратора/компрометации системы не гарантируется.
- Совместимость каждой версии Windows из старых редакций документации ещё не подтверждена.
