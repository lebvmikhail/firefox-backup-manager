# Руководство пользователя Firefox Backup Manager

Инструкция по развертыванию, первоначальной компиляции исходного кода, пошаговому конфигурированию параметров безопасности AES-256, анализу системных журналов логов, а также процедуре полного удаления программного модуля автоматического резервного копирования профилей браузера Firefox в Windows.

---

## 1. Системные требования и подготовка

Для корректной работы утилиты автоматизации в операционной системе должны быть выполнены следующие условия:
* **Операционная система**: Windows 7 / 8 / 10 / 11 (архитектуры x86 или x64).
* **Права доступа**: Настройку, первичную компиляцию и установку необходимо выполнять строго с правами Администратора (требуется для корректной регистрации триггеров задачи планировщика в системе).
* **Внешний архиватор**: В системе должен быть развернут официальный архиватор 7-Zip в стандартную программную директорию (`C:\Program Files\7-Zip` или `C:\Program Files (x86)\7-Zip`).

---

## 2. Первоначальная сборка проекта

Поскольку программа поставляется в виде открытого исходного кода для обеспечения прозрачности и безопасности личных данных, её необходимо скомпилировать на целевой машине:
1. Поместите исполняемый скрипт сборки `compile.bat` и исходный C#-код `compiler_code.cs` в общую изолированную локальную директорию.
2. Запустите файл `compile.bat` с правами администратора.
3. Дождитесь завершения работы консоли встроенного компилятора .NET Framework, которая выполнит сборку бинарного кода и выведет на экран контрольную сумму SHA-256 созданного приложения.
4. После закрытия терминала в текущей папке появится готовый к работе исполняемый файл `Firefox_Backup_Manager.exe`.

---

## 3. Первоначальная настройка авто-бэкапа

Для развертывания системы и инициализации первого автоматического снимка выполните следующие шаги:
1. Нажмите правой кнопкой мыши на созданный исполняемый файл `Firefox_Backup_Manager.exe` и выберите пункт «Запуск от имени администратора».
2. В открывшемся главном меню графического интерфейса нажмите кнопку «Включить / Настроить авто-бэкап».
3. **Выбор профиля**: Утилита автоматически просканирует систему и найдет все учетные записи вашего браузера. Выберите из списка нужный рабочий профиль и нажмите кнопку «Далее».
4. **Выбор папки**: В открывшемся системном окне проводника укажите целевой каталог для сохранения будущих резервных копий (например, внешний накопитель, сетевое хранилище NAS или защищенный локальный раздел диска).
5. **Безопасность архива**: Задайте секретный пароль для защиты ваших резервных копий от несанкционированного доступа третьих лиц:
   * Если пароль необходим — введите его в текстовое поле. Программа автоматически применит шифрование данных и оглавления по криптографическому стандарту AES-256 внутри защищенного контейнера `.7z`.
   * Если архивы должны создаваться открытыми — оставьте поле ввода пустым.
   * Нажмите кнопку «Завершить настройку».

> [!WARNING]
> **Контроль свободного пространства:** В момент нажатия кнопки «Завершить настройку» утилита автоматически оценит текущий физический размер вашего профиля Firefox и проверит наличие свободного места на целевом накопителе. Если свободного пространства недостаточно для проведения операции, программа прервёт транзакцию и выведет окно с предупреждением, защищая диск от критического переполнения.

После успешной проверки диска программа автоматически завершит активные процессы браузера для предотвращения повреждения баз данных, создаст локальный зашифрованный файл конфигурации `config.ini`, выполнит первый контрольный бэкап в выбранную папку, зарегистрирует триггеры задачи в планировщике Windows и закроется.

---

## 4. Контроль работы и чтение журналов (Логирование)

Утилита работает автономно при каждом включении персонального компьютера. Ручной запуск в процессе повседневной эксплуатации не требуется.

Для оперативного контроля состояния резервного копирования перейдите в выбранную ранее целевую директорию назначения. Внутри каталога будут создаваться следующие объекты:
* Защищенные криптоконтейнеры в формате `.7z`, именованные по сквозному шаблону: `[ИмяПрофиля]_[Дата_Время].7z` (копии старше 30 дней удаляются автоматически).
* Текстовый файл сквозного системного журнала **`backup_log.txt`**. Благодаря использованию кодировки UTF-8, лог корректно отображается в любом текстовом редакторе.

### Пример успешной записи в журнале при первом запуске:
```text
==================================================
[2026-08-17_20-42] [ПЕРВЫЙ ЗАПУСК] Создание стартовой копии...

7-Zip 26.02 (x64) : Copyright (c) 1999-2026 Igor Pavlov : 2026-06-25

Scanning the drive:
599 folders, 639 files, 160814198 bytes (154 MiB)

Creating archive: <Путь_К_Папке_Бэкапа>\<Имя_Профиля_Firefox>_2026-08-17_20-42.7z

Add new data to archive: 599 folders, 639 files, 160814198 bytes (154 MiB)

Files read from disk: 567
Archive size: 94415300 bytes (91 MiB)
Everything is Ok
[2026-08-17_20-42] [УСПЕХ] Мгновенный бэкап успешно завершен (AES-256).
==================================================
```

### Пример регулярной фоновой записи при автозапуске Windows:
```text
==================================================
[2026-08-17_22-02] [АВТОЗАПУСК ПК] Старт бэкапа.
[2026-08-17_22-03] [АРХИВАЦИЯ] 7-Zip успешно завершил работу.
[2026-08-17_22-03] [УСПЕХ] Скрытый автоматический бэкап успешно завершен.
==================================================
```

> [!NOTE]
> **Автоматическое обслуживание журнала:** Программный модуль самостоятельно контролирует дисковое пространство и следит за тем, чтобы лог-файл `backup_log.txt` не разрастался со временем. Максимальный объем файла ограничен лимитом в **5 МБ**. При превышении данного порога утилита автоматически выполняет ротацию — очищает устаревшие записи, предотвращая забивание диска.

## 5. Полное отключение и удаление системы

Если вам необходимо перенести программу на другую рабочую станцию или полностью отключить автоматическое копирование профилей:
1. Запустите исполняемый файл `Firefox_Backup_Manager.exe` с правами администратора.
2. Нажмите в графическом интерфейсе кнопку «Отключить авто-бэкап и удалить конфиг».
3. Программа самостоятельно сотрет зарегистрированную триггерную задачу из системного Планировщика задач Windows и удалит локальный файл настроек `config.ini`.
4. После завершения операции вы можете полностью удалить рабочую папку с исполняемыми файлами.

---

## 6. Приёмо-сдаточный тест (QA)

1. **Верификация архиватора**: Открыть командную строку Windows (`cmd`) и выполнить проверку пути: `where 7z.exe`. Система должна вернуть путь к исполняемому файлу архиватора в Program Files.
2. **Проверка компиляции**: Запустить процесс сборки через `compile.bat`. Убедиться, что в каталоге сгенерировался файл `Firefox_Backup_Manager.exe`, а размер бинарника больше 0 КБ.
3. **Проверка инициализации**: Пройти 3 шага мастера настройки. Убедиться, что в папке приложения создался файл `config.ini`, а в целевом каталоге бэкапов появился первый зашифрованный архив `.7z`.
4. **Контроль ротации логов**: Искусственно увеличить размер файла логов до 5.1 МБ. Запустить `Firefox_Backup_Manager.exe`. Убедиться, что размер файла `backup_log.txt` вернулся в пределы нормы, а старые лог-записи стерты.
5. **Проверка деинсталляции**: Выполнить процедуру удаления системы по шагам Раздела 5. Открыть системную утилиту `taskschd.msc` и убедиться, что задача резервного копирования полностью исчезла из библиотеки планировщика Windows.
