# Firefox Backup Manager

Небольшая Windows-утилита для резервного копирования профилей Mozilla Firefox в архивы 7-Zip.

> **Статус разработки:** ветка `development` находится на этапе проверки. Для неё настроены Windows CI, сборка приложения и smoke-тесты движка архивации на синтетическом профиле. Эти проверки не заменяют испытание на настоящем профиле Firefox, проверку задачи Планировщика от имени `SYSTEM` и реальное восстановление. Не используйте эту ветку как единственную систему защиты важных данных.

## Возможности текущей development-версии

- Обнаружение профилей Firefox через пользовательский `profiles.ini`.
- Создание архивов формата `.7z`; при заданном пароле используется AES-256 и шифрование заголовков (`-mhe=on`).
- Хранение зашифрованного представления пароля через Windows DPAPI (`DataProtectionScope.LocalMachine`).
- Передача пароля 7-Zip через перенаправленный стандартный ввод UTF-8, без помещения значения пароля в аргументы командной строки.
- Создание архива под временным именем, проверка командой `7z t` и публикация под окончательным именем только после успешных проверок.
- Сохранение старых архивов при неудачном резервировании.
- Отказ от резервирования, если обнаружен запущенный процесс Firefox; приложение не закрывает браузер принудительно.
- Защита от параллельного резервирования в одну папку.
- Фоновая задача Планировщика Windows при старте системы от имени `SYSTEM`; настройки разрешают запуск и продолжение работы от батареи.
- Журнал `backup_log.txt` и ротация архивов старше 30 дней после успешного резервирования.

## Важные ограничения

1. **Firefox должен быть закрыт.** Программа проверяет наличие процессов Firefox и отменяет резервирование, если обнаруживает хотя бы один. Она не завершает браузер автоматически. Проверка повторяется после создания и тестирования архива, но не блокирует запуск браузера атомарно.
2. **Передача пароля.** Значение пароля не попадает в командную строку процесса 7-Zip: приложение передаёт его через перенаправленный стандартный ввод UTF-8. Это снижает риск раскрытия через список аргументов процессов, но не защищает от локального администратора, отладчика или вредоносной программы с достаточными правами.
3. **Пустой пароль означает незашифрованный архив.** Это допустимая настройка, а не ошибка.
4. **DPAPI LocalMachine — не аппаратная привязка.** Защита относится к контексту машины Windows и не заменяет защиту от администратора или компрометации этой машины.
5. **Сетевые и съёмные хранилища не считаются проверенными.** Фоновая задача работает как `SYSTEM`; путь должен быть доступен этому контексту во время старта системы. Сначала проверяйте такой сценарий вручную.
6. **Восстановление через интерфейс пока не реализовано.** Проверка `7z t` подтверждает читаемость архива, но не заменяет пробное восстановление и запуск профиля Firefox.
7. **Ротация не сохраняет минимальное число копий.** После успешного резервирования могут удаляться архивы выбранного профиля старше 30 дней. Храните независимую копию на другом носителе.

## Системные требования

- Windows с .NET Framework 4.x и Windows PowerShell с модулем ScheduledTasks.
- Установленный 7-Zip с `7z.exe` в одном из стандартных каталогов Program Files.
- Права администратора для первоначальной настройки и регистрации задачи Планировщика Windows.
- Поддерживаемые версии Windows и .NET должны быть подтверждены испытаниями конкретного релиза.

## Сборка

1. Скачайте `compile.bat` и `compiler_code.cs` из одной и той же ревизии в один доступный для записи каталог.
2. Запустите `compile.bat`. Для самой компиляции права администратора не требуются.
3. Убедитесь, что компилятор завершился без ошибки и создан `Firefox_Backup_Manager.exe`.
4. SHA-256, выводимый скриптом, является контрольным отпечатком файла. Сам по себе он не удостоверяет автора или подлинность сборки.

## Автоматическая проверка

GitHub Actions собирает приложение на Windows runner, устанавливает 7-Zip, запускает smoke-тесты движка архивации и публикует артефакт сборки с SHA-256. Workflow запускается при push в `development` и при pull request в `main` или `development`. Результат конкретного запуска следует проверять на странице [GitHub Actions](https://github.com/lebvmikhail/firefox-backup-manager/actions/workflows/windows-build.yml).

Smoke-тест использует синтетический набор файлов с именами, похожими на некоторые файлы профиля Firefox. Он не подтверждает полную совместимость с настоящим профилем или успешность восстановления.
