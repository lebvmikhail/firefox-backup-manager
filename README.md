# Firefox Backup Manager

Легковесная утилита с открытым исходным кодом для автоматического резервного копирования профилей браузера Mozilla Firefox в Windows с поддержкой аппаратного шифрования AES-256.

## Основные возможности
* **Автоматическое обнаружение профилей**: парсинг `profiles.ini` с проверкой целостности баз данных (`places.sqlite`, `logins.json`).
* **Криптографическая защита**: создание архивов `.7z` с шифрованием данных и оглавления по стандарту **AES-256** (`-mhe=on`).
* **Безопасное хранение пароля**: защита мастер-пароля архива через системный компонент **Windows DPAPI** (`DataProtectionScope.LocalMachine`).
* **Автономная работа**: регистрация энергонезависимой задачи в Планировщике Windows (запуск при старте системы под учетной записью `SYSTEM`, в том числе при работе от аккумулятора).
* **Контроль ресурсов**: проверка свободного места на диске перед началом архивации, исключение временного кэша браузера, автоматическая ротация старых бэкапов (старше 30 дней) и лог-файла (при превышении 5 МБ).

## Системные требования
* **ОС**: Windows 7 / 8 / 10 / 11 (x86 или x64) с установленным .NET Framework 4.0+.
* **Архиватор**: установленный [7-Zip](https://7-zip.org) в стандартную директорию (`C:\Program Files\7-Zip` или `C:\Program Files (x86)\7-Zip`).
* **Права доступа**: запуск от имени Администратора для регистрации задачи в планировщике.

## Быстрый старт и сборка
Программа распространяется в виде открытого исходного кода для прозрачности и безопасности и компилируется локально встроенным компилятором Windows:

1. Скачайте файлы `compile.bat` и `compiler_code.cs` в одну папку.
2. Запустите `compile.bat` **от имени Администратора**.
3. Дождитесь завершения сборки и сверьте контрольные суммы SHA-256 в консоли. В папке появится готовый файл `Firefox_Backup_Manager.exe`.
4. Запустите `Firefox_Backup_Manager.exe` от имени Администратора и пройдите 3 шага мастера настройки.
